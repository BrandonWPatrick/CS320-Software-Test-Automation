# CS320-Software-Test-Automation

How do I make sure my code works and is secure?
I make sure my code works by writing unit tests for every main requirement. In this project, I tested things like field length limits, null values, and unique IDs. If something breaks, the tests show me right away. For security, I focus on input validation so invalid or bad data cant enter the system. Even small programs should protect their data.

How do I use user needs in a program?
I start by reading the requirements carefully and figuring out what rules the program has to follow. Then I turn those rules into actual code. After that, I write tests based on the same requirements to make sure everything works like its supposed to.

How do I design software?
I try to keep my design simple and organized. I separate different responsibilities into different classes. In this project, one class handled the contact data and another class handled managing contacts. Keeping things separated makes the program easier to understand, test, and update later.
